If you have not hosted it yet (about 60 seconds)

  1. Go to app.netlify.com/drop and sign in (free).
  2. Drag your index.html onto the page. It uploads and gives you a URL like https://random-name.netlify.app.
  3. Paste that URL into the box above. Both QR codes appear instantly.

Any static host works the same way (Vercel, GitHub Pages, or a cyreaux.com subpath). The URL is the only thing this kit needs.

Getting the leaderboard onto the screen

  1. On the laptop driving the monitor, open the Leaderboard / Monitor link above (it ends in #leaderboard).
  2. Press F11 for full screen. The board refreshes itself every 12 seconds, no clicking needed.
  3. It reads live from your Supabase, so every phone that finishes appears automatically. Nothing else to connect.
  4. Set the laptop to never sleep for the day (or keep the mouse awake) so the screen stays on.
